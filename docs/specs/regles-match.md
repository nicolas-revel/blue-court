# Règles de match et départage

Chaque phase a ses propres règles, pré-remplies avec les règles FFVB.

| Réglage | Options |
| --- | --- |
| Fin de match | Sets gagnants (1, 2 ou 3), nombre de sets fixe, ou temps limité |
| Points par set | Libre (15, 21, 25...), écart de 2 ou non, plafond optionnel |
| Tie-break | Oui ou non, nombre de points |
| Match nul | Autorisé ou non (utile pour les matchs au temps) |
| Points au classement | Par victoire, défaite, nul, forfait, selon le score en sets |
| Départage en poule | Ordre choisi parmi : victoires, points, ratio de sets, ratio de points, confrontation directe, tirage au sort |
| Arbitrage | Assignation automatique d'une équipe au repos, ou aucune |
