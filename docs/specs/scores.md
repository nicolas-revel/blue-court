# Saisie des scores

La table de marque reste la source de vérité, mais la saisie peut aussi se faire depuis un téléphone.

- **Table de marque** : un écran qui liste les matchs en cours par terrain, saisie rapide set par set.
- **Saisie sur téléphone** (option du tournoi) : l'arbitre ou un capitaine saisit le score via un code propre au match ou au terrain. La table valide ou corrige.
- **Score en direct** (option) : saisie point par point sur téléphone, pour que les spectateurs suivent le match en cours.
- Toute correction est historisée et recalcule les classements.
