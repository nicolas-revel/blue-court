# Inscriptions et constitution des équipes

Tout est réglable par tournoi.

| Réglage | Options |
| --- | --- |
| Joueurs par équipe | Libre (2, 3, 4, 6...), remplaçants optionnels |
| Mode d'inscription | Solo, duo, équipe complète, combinables |
| Constitution des équipes | Au hasard, équilibrée par niveau déclaré, ou manuelle |
| Contraintes | Mixité imposée, duos gardés ensemble, têtes de série |
| Inscription | Par l'organisateur, ou par lien public avant le tournoi |

L'organisateur peut toujours déplacer un joueur d'une équipe à l'autre après le tirage.
