# November 2, 2026

## Organizer accounts (#22)

- **Done by the AI**: organizer accounts with email and password (scrypt from `node:crypto`, no new hashing dependency), server-side sessions in an `HttpOnly`, `SameSite=Lax` cookie whose token is stored only as a hash, a global guard that closes every route unless it is marked `@Public()`, a socket handshake that checks the same cookie, tournaments owned by their organizer, rate-limited sign-up and sign-in (`@nestjs/throttler`); sign-in, sign-up and "My tournaments" screens; a service worker that drops old caches and never caches the organizer area; the spec [accounts.md](../specs/accounts.md).
- **Taken over by hand**: Nicolas chose email and password over a magic link or Google sign-in.
- **Decisions**: organizers only sign in (the scoring table's court code comes with score entry); sign-up is open; everything is closed by default and the public view will open its own routes; another organizer's tournament answers 404; tournaments created before accounts are deleted by the migration, as the app was never deployed. The list of public routes is pinned by a test rather than a convention, and sign-out also disconnects that session's live updates.
- **What got stuck**: a first end-to-end check read Next.js's empty route announcer instead of the form's error, since both have `role="alert"`.

## Forgotten password (#22, same PR)

- **Done by the AI**: a reset link by email (`nodemailer`, any SMTP server, written to the log when none is set), valid once for one hour, stored as a hash like sessions; setting a new password ends every session of the account and its live updates; "Mot de passe oublié" and "Nouveau mot de passe" screens; tests for the whole flow, then a browser run reading the link from the API log.
- **Taken over by hand**: Nicolas asked for it in the PR instead of leaving it out of v1.
- **Decisions**: the request answers the same with or without an account and sends the email in the background, so neither the answer nor its timing reveals accounts; the token goes after `#` in the link, so it never reaches a server log or a Referer header, and the page removes it from the address bar.
- **What got stuck**: a `git commit -a` left a new file out, which turned CI red until it was added; two pages first rendered at build time and froze the API address, caught by reading the build output.
