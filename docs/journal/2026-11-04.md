- **Taken over by hand**: nothing.
- **Decisions**: a malformed team or phase is skipped and the others are still checked, like after an invalid qualification; numbers are only checked for type (NaN included), so "whole number from 1" stays a configuration error with its own code; only own properties are read, so a kind such as `constructor` is refused.
- **What got stuck**: nothing notable; disabling one shape check made three of the new tests fail with the old `TypeError`, as expected.
