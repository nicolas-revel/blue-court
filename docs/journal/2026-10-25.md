## Engine: score validation and match winner (#2)

- **Done by the AI**: `validateScore`, which checks a score against the phase's match rules (points per set, 2-point margin, cap, tie-break set, sets to win, fixed sets, timed matches, forfeits) and returns the outcome or errors with a stable code and the set number; example tests and property-based tests (a generated finished match is always won by the team with the most sets; level fixed sets without draws are decided on total points, a perfect tie is refused; time-stopped and timed matches follow their rules).
- **Taken over by hand**: Nicolas chose to support an optional time limit on matches played in sets, the most common club format.
- **Decisions**: when time runs out, more sets wins, then the lead in the unfinished set (recommended default, taken while Nicolas was away); fixed sets that end level with no draw allowed are decided on total points; a perfect tie with no draw allowed is refused so the table plays one more point.
- **What got stuck**: two of the AI's own test expectations were wrong (25-23 is a valid deuce score in a set to 15; a total-points sum was miscounted); the code was right and the tests were fixed.
