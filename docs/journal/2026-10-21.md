## Engine: tournament data model (#1)

- **Done by the AI**: engine types (tournament, team, phase with format, match rules, ranking points, tie-breakers and qualification, match and score) and FFVB defaults as frozen constants; tests that express a typical club day (pools then level pools), every phase format, and set, timed and forfeit scores.
- **Reused**: `Match` extends the existing `Pairing` type from `roundRobin`, so generated pairings become matches without conversion.
- **Decisions**: phase formats, match rules and scores are discriminated unions (draw and tie-break settings exist only on the formats where they apply), so each new format is a compile-time change; FFVB forfeit points set to 0 and tie-breaker order to ranking points, set ratio, point ratio, to be confirmed by Nicolas.
